Python Scapy Packet Sniffer Script

Copy this Python script to run live packet sniffing on your local interface using Scapy:

from scapy.all import sniff, IP, TCP, UDP, ICMP

def packet_callback(packet):
    if packet.haslayer(IP):
        ip_src = packet[IP].src
        ip_dst = packet[IP].dst
        proto = packet[IP].proto
        print(f"[+] MZ-Sniffer: {ip_src} -> {ip_dst} | Protocol: {proto}")

print("[*] Starting MZ Network Sniffer...")
sniff(prn=packet_callback, store=0)
