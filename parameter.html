Perimeter Reconnaissance

Mapping public IP ranges, DNS enumeration, subdomains discovery, and discovering forgotten internet-facing hosts.

Parameter is an open-source reconnaissance framework that automates the process of gathering information about a target (domain, IP, or organization). It combines multiple reconnaissance techniques and tools into one easy-to-use interface.

Key Features
Automated subdomain enumeration
DNS & WHOIS information gathering
Web technology detection
Port scanning and service enumeration
SSL/TLS certificate analysis
Email and contact discovery
Website crawling and directory listing
Integration with multiple OSINT tools
Related Areas
OSINT Web Recon Bug Bounty Penetration Testing Threat Intelligence
How It Works?

1. Set Target

Domain / IP / Organization

2. Gather Info

DNS, Subdomains, Tech, Ports, etc.

3. Analyze

Filter, Sort, Check Results

4. Get Report

Detailed Output (TXT / JSON / HTML)

In Short: Parameter is a must-have tool in the recon phase of ethical hacking, penetration testing, and cybersecurity research.
