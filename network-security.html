Phase 2

Network Security Audits

Comprehensive scanning of open ports, misconfigured firewalls, and vulnerable network services across both internal enterprise environments and external cloud infrastructures.

Audit Coverage & Scope

External Network Audit

Testing perimeter defenses, exposed public IPs, cloud gateway misconfigurations (AWS Security Groups, Azure NSGs), and public-facing legacy services.

Internal Network Audit

Simulating insider threats to identify VLAN hopping, Active Directory domain weaknesses, SMB message signing gaps, and unpatched internal servers.

Firewall & Router Review

Auditing ACL (Access Control List) rules, detecting default SNMP community strings, weak SSH/Telnet configurations, and VPN gateway flaws.

Vulnerable Services Detection

Identifying outdated protocols (SSL v2/v3, TLS 1.0, RDP vulnerabilities like BlueKeep), default credentials, and unauthenticated network services.

Primary Security Toolstack

  • Nmap / Masscan: Network discovery and high-speed port scanning. Recon
  • Nessus Professional: Enterprise vulnerability assessment scanner. Assessment
  • Wireshark / TCPDump: Packet inspection and cleartext traffic analysis. Traffic Audit
  • Responder: LLMNR/NBT-NS poisoning for internal credential gathering. Internal Exploitation
